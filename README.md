# SideDrop downloads

Official Windows beta distribution assets for [SideDrop](https://sidedrop.io/).

Start with the [download and setup guide](https://sidedrop.io/download/). The beta is unsigned and each new PC needs assisted secure setup before pairing. Updates and certificate renewal are manual. Windows 11 x64 is the beta target; physical device and network compatibility varies.

This repository contains distribution assets, checksums and public release notes. The application's development source and history remain private. The automatically generated source archives contain only this distribution repository's documentation.

Download a versioned installer and its adjacent SHA-256 checksum from Releases. A matching hash compares bytes; it does not replace a trusted publisher signature. Stop if a download is unexpected, its hash differs, or security software reports a threat.

For beta setup questions, use the [private setup-request form](https://sidedrop.io/beta-setup/). Do not post files, private keys, pairing links, passwords or network details here.
